# Glossary

This glossary defines terms used throughout the BiodiverseR runtime build, packaging and release process.

## ADR

**Architecture Decision Record**

A document that captures a significant architectural or technical
decision, including the rationale, alternatives considered and
consequences.

Location:

```text
docs/adr/
```

---

## Alien::gdal

A Perl module used to locate or build GDAL libraries required by
Geo::GDAL::FFI.

Alien::gdal is one of the most complex runtime dependencies and can
significantly affect build duration.

---

## Alien::proj

A Perl module used to locate or build PROJ libraries required by
Geo::GDAL::FFI.

---

## Alien::geos::af

A Perl module used to locate or build GEOS libraries required by
Geo::GDAL::FFI.

---

## Biodiverse

The core biodiversity analysis application and Perl codebase.

Biodiverse provides the analysis functionality exposed to R users
through BiodiverseR.

---

## BiodiverseR

The R interface to Biodiverse.

BiodiverseR communicates with a local runtime process using an HTTP API
and exposes Biodiverse functionality through R objects and methods.

---

## Build Artifact

A file generated by a GitHub Actions workflow.

Examples include:

```text
BiodiverseR
BiodiverseR.exe
BiodiverseR_macos_arm64_v0.2.0.zip
```

---

## CI Artifact

An artifact generated during normal CI validation runs.

CI artifacts are identified using the source commit SHA.

Example:

```text
BiodiverseR_macos_arm64_d2ddf75
```

CI artifacts are intended for testing and traceability.

---

## Geo::GDAL::FFI

A Perl module that provides access to GDAL functionality using FFI
(Foreign Function Interface).

Geo::GDAL::FFI is used by Biodiverse and is one of the most significant
runtime dependencies.

---

## GitHub Release

A published versioned release associated with a Git tag.

Example:

```text
v0.2.0
```

GitHub Releases contain runtime assets used by BiodiverseR.

---

## Platform Identifier

A platform-specific identifier used within release metadata.

Current values:

```text
windows
macos
linux
```

These identifiers are used by BiodiverseR to select the correct runtime
package.

---

## Portable Runtime

A pre-built runtime environment containing Biodiverse and its
dependencies.

The Windows runtime currently follows a portable-runtime model using
pre-built Strawberry Perl distributions.

---

## Release Asset

A runtime package attached to a GitHub Release.

Examples:

```text
BiodiverseR_windows_x64_v0.2.0.zip
BiodiverseR_macos_arm64_v0.2.0.zip
```

Release assets are intended for distribution and installation by 
BiodiverseR users.

---

## Release Manifest

The JSON file used by BiodiverseR to locate runtime releases.

File:

```text
releases.json
```

The manifest describes:

- Current runtime version.
- Available runtime releases.
- Platform-specific download URLs.
- SHA-256 checksums.

---

## Runtime

A packaged Biodiverse execution environment used by BiodiverseR.

The runtime contains:

- Perl
- Biodiverse
- Runtime dependencies
- Local HTTP API server

The runtime allows users to access Biodiverse functionality without
manually installing Biodiverse or Perl.

---

## Runtime Configuration

Build configuration stored in:

```text
.github/runtime-config.yml
```

The configuration file contains shared and platform-specific settings
used by runtime build workflows.

---

## Runtime Installation Test

An end-to-end validation test that verifies BiodiverseR can:

- Download a runtime.
- Install a runtime.
- Start a runtime.
- Create a `basedata` object.
- Interact successfully with the runtime.

---

## Runtime Startup Test

A validation test that confirms a packaged runtime executable can be
started successfully and responds through the runtime API.

---

## Runtime Version

The version of a published runtime release.

Examples:

```text
v0.1.0-alpha
v0.2.0
```

Runtime versions are tracked in:

```text
releases.json
```

and GitHub Releases.

---

## SHA-256

Cryptographic checksum used to verify runtime package integrity.

BiodiverseR verifies downloaded runtime packages against the SHA-256
value stored in the release manifest before installation.

---

## Strawberry Perl

A Windows Perl distribution used by the Biodiverse Windows runtime build
process.

Current Windows runtime builds use Strawberry Perl 5.38.4.1.

---

## Tag

A Git reference used to identify runtime release versions.

Example:

```bash
git tag v0.2.0
git push origin v0.2.0
```

Tags trigger the runtime release workflow.

---

## Workflow

A GitHub Actions workflow used to build, test or release runtimes.

Examples:

```text
windows.yml
macos-runtime.yml
macos-ci.yml
releases.yml
linux-test.yml
```

---

## yq

A command-line tool used to read values from YAML files.

The runtime build workflows use `yq` to load configuration values from:

```text
.github/runtime-config.yml
```
